# Summary of Work Process

In this assignment I learned how to build responsive web pages using
CSS media queries and Bootstrap 5.3.

- Task 0: Used media queries to change font sizes for mobile, tablet, and desktop.
- Task 1: Built a 3-box layout with `flex` and media queries — 1 / 2 / 3 boxes per row.
- Task 2: Rebuilt the same layout using Bootstrap's 12-column grid (`col-12 col-md-6 col-lg-4`).
- Task 3: Created a responsive navbar with logo, links, and a hamburger menu.
- Task 4: Combined everything into a portfolio page with cards, sidebar, and footer.

Main challenge: I forgot to add `box-sizing: border-box`, so boxes were too wide
and didn't fit in one row. After fixing it, everything worked correctly.
